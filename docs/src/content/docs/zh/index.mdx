## 文档外壳

Page 用 RefineUI override 替换 Starlight 的外壳。

- 页眉包含你配置的链接、命令搜索和主题按钮
- 桌面端可调整宽度的侧栏，窄屏为抽屉
- 页脚包含导航、社交链接、版权和语言选择
- 浅色与深色来自 RefineUI 语义令牌

## 在页面中使用组件

所有 RefineUI 组件都从 `@pelagornis/page/components` 引入。

```mdx
import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
```
