## 在 MDX 中使用

`Tooltip` 由共享 React 状态的多个部件组成。写在 MDX 中的子元素会各自渲染成独立的岛，部件之间无法互通。请像上面的示例一样在 `.tsx` 文件中组合，再导入该文件。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import TooltipExample from "../../components/TooltipExample";

<TooltipExample client:load />
```

`client:load` 会在页面加载时水合该岛。位于页面靠下位置的内容请使用 `client:visible`。

## 在 Markdoc 中使用

Markdoc 标签渲染的是 Astro 组件，而这个组件需要客户端状态。请把示例包进一个负责水合的 `.astro` 文件，再把该文件注册为标签。

```astro title="src/components/markdoc/TooltipExample.astro"
---
import TooltipExample from "../TooltipExample";
---

<TooltipExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "tooltip-example": {
      render: component("./src/components/markdoc/TooltipExample.astro"),
      selfClosing: true,
    },
  },
});
```

```md title="src/content/docs/example.mdoc"
{% tooltip-example /%}
```
