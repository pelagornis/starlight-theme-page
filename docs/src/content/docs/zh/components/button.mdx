## 在 MDX 中使用

`Button` 可以直接写在 `.mdx` 页面中。在 frontmatter 下方导入即可。它在服务器端渲染，不需要 client 指令。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

## 在 Markdoc 中使用

`pageMarkdoc()` 会为这个组件注册 `button` 标签。在 `markdoc.config.mjs` 中添加一次预设（见[在 Markdoc 中使用](/zh/guides/markdoc/)），就能在任意 `.mdoc` 页面中使用该标签。

```md title="src/content/docs/example.mdoc"
{% button variant="primary" %}Continue{% /button %}
{% button variant="outline" size="sm" %}Cancel{% /button %}
```

属性的名称和取值与 React props 相同。
