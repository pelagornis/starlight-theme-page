页面中可以混用 Starlight 自带组件和 RefineUI 组件。主题用 RefineUI 组件渲染自带组件，所以两者看起来一致，已有页面无需修改。

## Aside

`<Aside>` 使用 RefineUI Alert 渲染。note 使用信息色，tip 使用成功色，caution 使用警告色，danger 使用错误色。Markdown 的 `:::note` 语法也会得到同样的 Alert。设置 `icon` 会替换 Alert 的图标。

<Aside>注释使用信息色。</Aside>

<Aside type="tip">提示使用成功色。</Aside>

<Aside type="caution" title="检查你的配置">注意使用警告色。</Aside>

<Aside type="danger">危险使用错误色。</Aside>

:::tip[Markdown 语法]
用 `:::tip[Markdown 语法]` 编写。
:::

## Badge

`<Badge>` 使用 RefineUI Badge 渲染。RefineUI Badge 只有一种尺寸，所以 `size` 不起作用。

## Tabs

`<Tabs>` 使用 RefineUI Tabs 渲染。`syncKey` 相同的标签组会一起切换，所选标签在其他页面也会保留。在第一组中选择包管理器，第二组也会跟着切换。

<Tabs syncKey="package-manager">
  <TabItem label="bun" icon="bun">

```sh
bun add @pelagornis/page
```

  </TabItem>
  <TabItem label="npm" icon="npm">

```sh
npm install @pelagornis/page
```

  </TabItem>
</Tabs>

<Tabs syncKey="package-manager">
  <TabItem label="bun">

```sh
bun run dev
```

  </TabItem>
  <TabItem label="npm">

```sh
npm run dev
```

  </TabItem>
</Tabs>

## Steps

`<Steps>` 沿用 Starlight 的编号列表，每个步骤里都可以放代码块和段落。编号和步骤之间的连线使用与纵向 RefineUI Stepper 相同的令牌。

<Steps>

1. 安装插件。

   ```sh
   bun add @pelagornis/page
   ```

2. 把 `pagePlugin()` 加到 Starlight 的 `plugins` 中。

3. 运行开发服务器。

   ```sh
   bun run dev
   ```

</Steps>

## Card

`<Card>` 和 `<LinkCard>` 使用带边框的 RefineUI Card 渲染。链接卡片是可交互的 Card，整张卡片都是链接。`<CardGrid>` 在宽屏上将卡片排成两列。

<CardGrid>
  <Card title="外壳" icon="rocket">
    页眉、侧栏、搜索和页脚来自 RefineUI。
  </Card>
  <Card title="组件" icon="puzzle">
    所有 RefineUI 组件都可以从 `@pelagornis/page/components` 导入。
  </Card>
</CardGrid>

## 文件树

`<FileTree>` 使用 RefineUI Tree 渲染。文件夹默认展开，**加粗**的条目会被选中，名称后的文字显示为注释。

<FileTree>
- astro.config.ts 注册 pagePlugin()
- markdoc.config.mjs
- src/
  - content/
    - docs/
      - index.mdx
      - guides/
        - **getting-started.mdx**
        - …
</FileTree>
