Starlight Theme Page 是受 [starlight-theme-black](https://github.com/adrian-ub/starlight-theme-black) 启发的现代 Starlight 主题。

## 快速开始

<PackageManagerTabs />

### 2. Astro 配置

在您的 `astro.config.mjs` 文件中添加插件：

```js
import { defineConfig } from "astro/config";
import starlight from "@astrojs/starlight";
import pagePlugin from "@pelagornis/page";

export default defineConfig({
  integrations: [
    starlight({
      plugins: [pagePlugin()],
    }),
  ],
});
```

### 3. 添加样式

在您的 `src/styles/global.css` 文件中添加样式：

```css
@import "@pelagornis/page/styles";
```

## 自定义

### 颜色更改

您可以使用 CSS 变量轻松更改主题颜色：

```css
:root {
  --page-accent: hsl(220, 100%, 50%);
  --page-accent-hover: hsl(220, 100%, 40%);
  --page-bg: hsl(0, 0%, 100%);
  --page-text: hsl(0, 0%, 10%);
}
```

### 导航链接

您可以在插件设置中配置导航链接：

```js
pagePlugin({
  navLinks: [
    {
      label: "Blog",
      link: "/blog/",
      badge: "New",
    },
  ],
});
```
