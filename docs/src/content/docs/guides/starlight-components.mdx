## Steps

`<Steps>` keeps Starlight's numbered list, so a step can hold code blocks and paragraphs. The markers and the line between them use the same tokens as a vertical RefineUI Stepper.

<Steps>

1. Install the plugin.

   ```sh
   bun add @pelagornis/page
   ```

2. Add `pagePlugin()` to Starlight's `plugins`.

3. Run the dev server.

   ```sh
   bun run dev
   ```

</Steps>

## Cards

`<Card>` and `<LinkCard>` render as an outlined RefineUI Card. A link card is an interactive Card, and the whole card is the link. `<CardGrid>` lays them out in two columns on wide screens.
