Pages can mix Starlight's built-in components with RefineUI components. The theme renders the built-in ones with RefineUI components, so both sets look alike and existing pages need no changes.

## Asides

`<Aside>` renders as a RefineUI Alert: note uses the info colors, tip success, caution warning, and danger error. The `:::note` Markdown syntax gives the same Alert. An `icon` replaces the Alert's icon.

<Aside>A note uses the info colors.</Aside>

<Aside type="tip">A tip uses the success colors.</Aside>

<Aside type="caution" title="Check your config">A caution uses the warning colors.</Aside>

<Aside type="danger">A danger aside uses the error colors.</Aside>

:::tip[Markdown syntax]
Written with `:::tip[Markdown syntax]`.
:::

## Badges

`<Badge>` renders as a RefineUI Badge. RefineUI Badge has one size, so `size` has no effect.

<Badge text="Default" /> <Badge text="Note" variant="note" /> <Badge text="Tip" variant="tip" /> <Badge text="Caution" variant="caution" /> <Badge text="Danger" variant="danger" /> <Badge text="Success" variant="success" />

## Tabs

`<Tabs>` renders as RefineUI Tabs. Tab sets with the same `syncKey` switch together, and the choice is remembered across pages. Pick a package manager in the first set and the second one follows.

<Tabs syncKey="package-manager">
  <TabItem label="bun" icon="bun">

```sh
bun add @pelagornis/page
```

  </TabItem>
  <TabItem label="npm" icon="npm">

```sh
npm install @pelagornis/page
```

  </TabItem>
</Tabs>

<Tabs syncKey="package-manager">
  <TabItem label="bun">

```sh
bun run dev
```

  </TabItem>
  <TabItem label="npm">

```sh
npm run dev
```

  </TabItem>
</Tabs>

## Link buttons

`<LinkButton>` is a link drawn as a RefineUI Button. `primary`, `secondary`, and `minimal` match the primary, outline, and ghost buttons.

<LinkButton href="/guides/getting-started/">Get started</LinkButton> <LinkButton href="/components/" variant="secondary" icon="right-arrow">Components</LinkButton> <LinkButton href="https://ui.pelagornis.com/" variant="minimal" icon="external">RefineUI</LinkButton>

## Steps

`<Steps>` keeps Starlight's numbered list, so a step can hold code blocks and paragraphs. The markers and the line between them use the same tokens as a vertical RefineUI Stepper.

<Steps>

1. Install the plugin.

   ```sh
   bun add @pelagornis/page
   ```

2. Add `pagePlugin()` to Starlight's `plugins`.

3. Run the dev server.

   ```sh
   bun run dev
   ```

</Steps>

## Cards

`<Card>` and `<LinkCard>` render as an outlined RefineUI Card. A link card is an interactive Card, and the whole card is the link. `<CardGrid>` lays them out in two columns on wide screens.

<CardGrid>
  <Card title="Shell" icon="rocket">
    Header, sidebar, search, and footer come from RefineUI.
  </Card>
  <Card title="Components" icon="puzzle">
    Every RefineUI component is exported from `@pelagornis/page/components`.
  </Card>
</CardGrid>

## File tree

`<FileTree>` renders as a RefineUI Tree. Directories start open, a **bold** entry is selected, and text after the name is a comment.

<FileTree>
- astro.config.ts registers pagePlugin()
- markdoc.config.mjs
- src/
  - content/
    - docs/
      - index.mdx
      - guides/
        - **getting-started.mdx**
        - …
</FileTree>
