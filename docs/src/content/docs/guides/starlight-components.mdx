Pages can mix Starlight's built-in components with RefineUI components. The theme restyles the built-in ones with the same tokens, so both sets look alike.

## Asides

<Aside>A note uses the info colors.</Aside>

<Aside type="tip">A tip uses the success colors.</Aside>

<Aside type="caution" title="Check your config">A caution uses the warning colors.</Aside>

<Aside type="danger">A danger aside uses the error colors.</Aside>

## Steps

<Steps>

1. Install the plugin.

2. Add `pagePlugin()` to Starlight's `plugins`.

3. Run the dev server.

</Steps>
