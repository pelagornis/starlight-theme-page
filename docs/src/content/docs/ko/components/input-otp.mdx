## MDX에서 사용

`Input OTP` 컴포넌트는 React 상태를 공유하는 여러 부분으로 이루어집니다. MDX에 적은 자식은 각각 별도의 아일랜드로 렌더링되어 부분끼리 서로 닿지 않습니다. 위 예제처럼 `.tsx` 파일에서 조합한 뒤 그 파일을 가져오세요.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import InputOtpExample from "../../components/InputOtpExample";

<InputOtpExample client:load />
```

`client:load`는 페이지를 불러올 때 아일랜드를 하이드레이션합니다. 페이지 아래쪽에 있는 콘텐츠에는 `client:visible`을 쓰세요.

## Markdoc에서 사용

Markdoc 태그는 Astro 컴포넌트를 렌더링하는데, 이 컴포넌트는 클라이언트 상태가 필요합니다. 예제를 하이드레이션하는 `.astro` 파일로 감싼 뒤, 그 파일을 태그로 등록하세요.

```astro title="src/components/markdoc/InputOtpExample.astro"
---
import InputOtpExample from "../InputOtpExample";
---

<InputOtpExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "input-otp-example": {
      render: component("./src/components/markdoc/InputOtpExample.astro"),
      selfClosing: true,
    },
  },
});
```

```md title="src/content/docs/example.mdoc"
{% input-otp-example /%}
```
