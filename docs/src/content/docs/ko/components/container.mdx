## MDX에서 사용

`Container` 컴포넌트는 `.mdx` 페이지에 바로 쓸 수 있습니다. frontmatter 아래에서 가져오세요. 서버에서 렌더링되므로 client 지시어가 필요 없습니다.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Container } from "@pelagornis/page/components";

<Container padding="sizeXXLarge">
  Centered content
</Container>
```

## Markdoc에서 사용

`pageMarkdoc()`가 이 컴포넌트의 `container` 태그를 등록합니다. `markdoc.config.mjs`에 프리셋을 한 번 추가한 뒤([Markdoc에서 사용](/ko/guides/markdoc/) 참고), 어느 `.mdoc` 페이지에서나 태그를 쓰세요.

```md title="src/content/docs/example.mdoc"
{% container padding="sizeXXLarge" %}
Centered content
{% /container %}
```

속성 이름과 값은 React props와 같습니다.
