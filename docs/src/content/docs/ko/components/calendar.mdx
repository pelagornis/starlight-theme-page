## MDX에서 사용

`Calendar` 컴포넌트는 `.mdx` 페이지에 바로 쓸 수 있습니다. frontmatter 아래에서 가져오세요. 입력에 반응하므로 `client:load`를 붙여 하이드레이션합니다.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Calendar } from "@pelagornis/page/components";

<Calendar client:load weekStartsOn={1} />
```

## Markdoc에서 사용

Markdoc 태그는 Astro 컴포넌트를 렌더링하는데, 이 컴포넌트는 클라이언트 상태가 필요합니다. 예제를 하이드레이션하는 `.astro` 파일로 감싼 뒤, 그 파일을 태그로 등록하세요.

```astro title="src/components/markdoc/CalendarExample.astro"
---
import CalendarExample from "../CalendarExample";
---

<CalendarExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "calendar-example": {
      render: component("./src/components/markdoc/CalendarExample.astro"),
      selfClosing: true,
    },
  },
});
```

```md title="src/content/docs/example.mdoc"
{% calendar-example /%}
```
