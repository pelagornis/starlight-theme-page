## 문서 셸

Page는 Starlight 크롬을 RefineUI override로 바꿉니다.

- 설정한 링크, 커맨드 검색, 테마 버튼이 있는 헤더
- 데스크톱의 너비 조절 사이드바와 좁은 화면의 서랍
- 탐색, 소셜 링크, 저작권, 언어 선택이 있는 푸터
- RefineUI 시맨틱 토큰의 라이트·다크 테마

## 페이지에서 쓰는 컴포넌트

모든 RefineUI 컴포넌트는 `@pelagornis/page/components`에서 가져옵니다.

```mdx
import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
```

- [MDX에서 사용](/ko/guides/mdx/): import, 클라이언트 지시어, 복합 컴포넌트
- [Markdoc에서 사용](/ko/guides/markdoc/): `pageMarkdoc()` 프리셋과 태그
- [컴포넌트](/ko/components/): 59개 컴포넌트의 미리보기, 예제 소스, props
