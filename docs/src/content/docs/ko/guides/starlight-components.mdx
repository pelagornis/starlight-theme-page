페이지에서 Starlight 기본 컴포넌트와 RefineUI 컴포넌트를 함께 쓸 수 있습니다. 테마가 기본 컴포넌트를 RefineUI 컴포넌트로 그려서 두 종류가 똑같이 보이고, 기존 페이지는 고칠 필요가 없습니다.

## Aside

`<Aside>`는 RefineUI Alert로 그려집니다. note는 정보, tip은 성공, caution은 경고, danger는 오류 색을 씁니다. Markdown의 `:::note` 문법도 같은 Alert가 됩니다. `icon`을 주면 Alert 아이콘이 바뀝니다.

<Aside>노트는 정보 색을 씁니다.</Aside>

<Aside type="tip">팁은 성공 색을 씁니다.</Aside>

<Aside type="caution" title="설정을 확인하세요">주의는 경고 색을 씁니다.</Aside>

<Aside type="danger">위험은 오류 색을 씁니다.</Aside>

:::tip[Markdown 문법]
`:::tip[Markdown 문법]`으로 썼습니다.
:::

## Badge

`<Badge>`는 RefineUI Badge로 그려집니다. RefineUI Badge는 크기가 하나라서 `size`는 적용되지 않습니다.

<Badge text="Default" /> <Badge text="Note" variant="note" /> <Badge text="Tip" variant="tip" /> <Badge text="Caution" variant="caution" /> <Badge text="Danger" variant="danger" /> <Badge text="Success" variant="success" />

## Tabs

`<Tabs>`는 RefineUI Tabs로 그려집니다. `syncKey`가 같은 탭 묶음은 함께 바뀌고, 고른 탭은 다른 페이지에서도 유지됩니다. 첫 번째 묶음에서 패키지 매니저를 고르면 두 번째 묶음도 따라 바뀝니다.

<Tabs syncKey="package-manager">
  <TabItem label="bun" icon="bun">

```sh
bun add @pelagornis/page
```

  </TabItem>
  <TabItem label="npm" icon="npm">

```sh
npm install @pelagornis/page
```

  </TabItem>
</Tabs>

<Tabs syncKey="package-manager">
  <TabItem label="bun">

```sh
bun run dev
```

  </TabItem>
  <TabItem label="npm">

```sh
npm run dev
```

  </TabItem>
</Tabs>

## LinkButton

`<LinkButton>`은 RefineUI Button 모양의 링크입니다. `primary`, `secondary`, `minimal`은 각각 primary, outline, ghost 버튼에 대응합니다.

<LinkButton href="/ko/guides/getting-started/">시작하기</LinkButton> <LinkButton href="/ko/components/" variant="secondary" icon="right-arrow">컴포넌트</LinkButton> <LinkButton href="https://ui.pelagornis.com/" variant="minimal" icon="external">RefineUI</LinkButton>

## Steps

`<Steps>`는 Starlight의 번호 목록 구조를 그대로 써서 단계 안에 코드 블록이나 여러 문단을 넣을 수 있습니다. 번호와 단계 사이의 선은 세로 RefineUI Stepper와 같은 토큰으로 그립니다.

<Steps>

1. 플러그인을 설치합니다.

   ```sh
   bun add @pelagornis/page
   ```

2. Starlight의 `plugins`에 `pagePlugin()`을 추가합니다.

3. dev 서버를 실행합니다.

   ```sh
   bun run dev
   ```

</Steps>

## Card

`<Card>`와 `<LinkCard>`는 테두리형 RefineUI Card로 그려집니다. 링크 카드는 상호작용형 Card라서 카드 전체가 링크입니다. `<CardGrid>`는 넓은 화면에서 카드를 두 열로 배치합니다.

<CardGrid>
  <Card title="셸" icon="rocket">
    헤더, 사이드바, 검색, 푸터는 RefineUI입니다.
  </Card>
  <Card title="컴포넌트" icon="puzzle">
    모든 RefineUI 컴포넌트를 `@pelagornis/page/components`에서 가져올 수 있습니다.
  </Card>
</CardGrid>

- markdoc.config.mjs
- src/
  - content/
    - docs/
      - index.mdx
      - guides/
        - **getting-started.mdx**
        - …
</FileTree>
