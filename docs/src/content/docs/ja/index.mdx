## ドキュメントシェル

Page は Starlight のクロムを RefineUI の override に置き換えます。

- 設定したリンク、コマンド検索、テーマボタンがあるヘッダー
- デスクトップでは幅を変えられるサイドバー、狭い画面ではドロワー
- ナビゲーション、ソーシャルリンク、著作権、言語選択があるフッター
- RefineUI のセマンティックトークンによるライトとダーク

## ページで使うコンポーネント

RefineUI のコンポーネントはすべて `@pelagornis/page/components` から読み込めます。

```mdx
import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
```

- [MDX で使う](/ja/guides/mdx/): import、クライアントディレクティブ、複合コンポーネント
- [Markdoc で使う](/ja/guides/markdoc/): `pageMarkdoc()` プリセットとタグ
- [コンポーネント](/ja/components/): 59 個のコンポーネントのプレビュー、例、props
