ページでは Starlight 標準のコンポーネントと RefineUI のコンポーネントを混ぜて使えます。テーマが標準コンポーネントを同じトークンで描き直すので、両者は同じように見えます。

## Aside

<Aside>ノートは情報の色を使います。</Aside>

<Aside type="tip">ヒントは成功の色を使います。</Aside>

<Aside type="caution" title="設定を確認してください">注意は警告の色を使います。</Aside>

<Aside type="danger">危険はエラーの色を使います。</Aside>

## Steps

<Steps>

1. プラグインをインストールします。

2. Starlight の `plugins` に `pagePlugin()` を追加します。

3. dev サーバーを起動します。

</Steps>
