## Aside

<Aside>ノートは情報の色を使います。</Aside>

<Aside type="tip">ヒントは成功の色を使います。</Aside>

<Aside type="caution" title="設定を確認してください">注意は警告の色を使います。</Aside>

<Aside type="danger">危険はエラーの色を使います。</Aside>

## Steps

`<Steps>` は Starlight の番号付きリストをそのまま使うので、各ステップにコードブロックや段落を入れられます。番号とステップをつなぐ線は、縦向きの RefineUI Stepper と同じトークンで描かれます。

<Steps>

1. プラグインをインストールします。

   ```sh
   bun add @pelagornis/page
   ```

2. Starlight の `plugins` に `pagePlugin()` を追加します。

3. dev サーバーを起動します。

   ```sh
   bun run dev
   ```

</Steps>

## Card

`<Card>` と `<LinkCard>` は枠線付きの RefineUI Card で描画されます。リンクカードはインタラクティブな Card で、カード全体がリンクになります。`<CardGrid>` は広い画面でカードを 2 列に並べます。

<CardGrid>
  <Card title="シェル" icon="rocket">
    ヘッダー、サイドバー、検索、フッターは RefineUI です。
  </Card>
  <Card title="コンポーネント" icon="puzzle">
    すべての RefineUI コンポーネントは `@pelagornis/page/components` から使えます。
  </Card>
</CardGrid>

## ファイルツリー

`<FileTree>` は RefineUI Tree で描画されます。フォルダーは開いた状態で始まり、**太字**の項目が選択され、名前の後のテキストはコメントとして表示されます。

<FileTree>
- astro.config.ts pagePlugin() を登録
- markdoc.config.mjs
- src/
  - content/
    - docs/
      - index.mdx
      - guides/
        - **getting-started.mdx**
        - …
</FileTree>
