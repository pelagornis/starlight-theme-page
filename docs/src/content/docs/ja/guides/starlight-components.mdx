ページでは Starlight 標準のコンポーネントと RefineUI のコンポーネントを混ぜて使えます。テーマが標準コンポーネントを RefineUI コンポーネントで描くので、両者は同じように見え、既存のページを変更する必要はありません。

## Aside

`<Aside>` は RefineUI Alert で描画されます。note は情報、tip は成功、caution は警告、danger はエラーの色を使います。Markdown の `:::note` 記法も同じ Alert になります。`icon` を指定すると Alert のアイコンが置き換わります。

<Aside>ノートは情報の色を使います。</Aside>

<Aside type="tip">ヒントは成功の色を使います。</Aside>

<Aside type="caution" title="設定を確認してください">注意は警告の色を使います。</Aside>

<Aside type="danger">危険はエラーの色を使います。</Aside>

:::tip[Markdown 記法]
`:::tip[Markdown 記法]` で書いています。
:::

## Badge

`<Badge>` は RefineUI Badge で描画されます。RefineUI Badge のサイズは 1 種類なので、`size` は効きません。

<Badge text="Default" /> <Badge text="Note" variant="note" /> <Badge text="Tip" variant="tip" /> <Badge text="Caution" variant="caution" /> <Badge text="Danger" variant="danger" /> <Badge text="Success" variant="success" />

## Tabs

`<Tabs>` は RefineUI Tabs で描画されます。`syncKey` が同じタブは一緒に切り替わり、選んだタブは他のページでも保たれます。1 つ目のタブでパッケージマネージャーを選ぶと、2 つ目も切り替わります。

<Tabs syncKey="package-manager">
  <TabItem label="bun" icon="bun">

```sh
bun add @pelagornis/page
```

  </TabItem>
  <TabItem label="npm" icon="npm">

```sh
npm install @pelagornis/page
```

  </TabItem>
</Tabs>

<Tabs syncKey="package-manager">
  <TabItem label="bun">

```sh
bun run dev
```

  </TabItem>
  <TabItem label="npm">

```sh
npm run dev
```

  </TabItem>
</Tabs>

## LinkButton

`<LinkButton>` は RefineUI Button の見た目のリンクです。`primary`、`secondary`、`minimal` はそれぞれ primary、outline、ghost のボタンに対応します。

<LinkButton href="/ja/guides/getting-started/">はじめに</LinkButton> <LinkButton href="/ja/components/" variant="secondary" icon="right-arrow">コンポーネント</LinkButton> <LinkButton href="https://ui.pelagornis.com/" variant="minimal" icon="external">RefineUI</LinkButton>

## Steps

`<Steps>` は Starlight の番号付きリストをそのまま使うので、各ステップにコードブロックや段落を入れられます。番号とステップをつなぐ線は、縦向きの RefineUI Stepper と同じトークンで描かれます。

<Steps>

1. プラグインをインストールします。

   ```sh
   bun add @pelagornis/page
   ```

2. Starlight の `plugins` に `pagePlugin()` を追加します。

3. dev サーバーを起動します。

   ```sh
   bun run dev
   ```

</Steps>

## Card

`<Card>` と `<LinkCard>` は枠線付きの RefineUI Card で描画されます。リンクカードはインタラクティブな Card で、カード全体がリンクになります。`<CardGrid>` は広い画面でカードを 2 列に並べます。

<CardGrid>
  <Card title="シェル" icon="rocket">
    ヘッダー、サイドバー、検索、フッターは RefineUI です。
  </Card>
  <Card title="コンポーネント" icon="puzzle">
    すべての RefineUI コンポーネントは `@pelagornis/page/components` から使えます。
  </Card>
</CardGrid>

<LinkCard title="はじめに" href="/ja/guides/getting-started/" description="テーマをインストールしてプラグインを登録します。" />

## ファイルツリー

`<FileTree>` は RefineUI Tree で描画されます。フォルダーは開いた状態で始まり、**太字**の項目が選択され、名前の後のテキストはコメントとして表示されます。

<FileTree>
- astro.config.ts pagePlugin() を登録
- markdoc.config.mjs
- src/
  - content/
    - docs/
      - index.mdx
      - guides/
        - **getting-started.mdx**
        - …
</FileTree>
