### 2. Astro 設定

`astro.config.mjs`ファイルにプラグインを追加してください：

```js
import { defineConfig } from "astro/config";
import starlight from "@astrojs/starlight";
import pagePlugin from "@pelagornis/page";

export default defineConfig({
  integrations: [
    starlight({
      plugins: [pagePlugin()],
    }),
  ],
});
```

### 3. スタイル追加

`src/styles/global.css`ファイルにスタイルを追加してください：

```css
@import "@pelagornis/page/styles";
```

## カスタマイゼーション

### 色の変更

CSS 変数を使用してテーマの色を簡単に変更できます：

```css
:root {
  --page-accent: hsl(220, 100%, 50%);
  --page-accent-hover: hsl(220, 100%, 40%);
  --page-bg: hsl(0, 0%, 100%);
  --page-text: hsl(0, 0%, 10%);
}
```

### ナビゲーションリンク

プラグイン設定でナビゲーションリンクを設定できます：

```js
pagePlugin({
  navLinks: [
    {
      label: "Blog",
      link: "/blog/",
      badge: "New",
    },
  ],
});
```
