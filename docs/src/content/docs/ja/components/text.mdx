## MDX で使う

`Text` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Text } from "@pelagornis/page/components";

<Text as="p" variant="titleMd">Title medium</Text>
<Text variant="captionMd">Caption</Text>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `text` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% text as="p" variant="titleMd" %}Title medium{% /text %}
```

属性の名前と値は React の props と同じです。
