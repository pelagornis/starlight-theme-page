## MDX で使う

`Label` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Label } from "@pelagornis/page/components";

<Label htmlFor="email" required>Email address</Label>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `label` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% label htmlFor="email" required=true %}Email address{% /label %}
```

属性の名前と値は React の props と同じです。
