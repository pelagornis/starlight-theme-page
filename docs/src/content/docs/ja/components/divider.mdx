## MDX で使う

`Divider` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Divider } from "@pelagornis/page/components";

<Divider />

<Divider layout="content" align="center">Or continue with</Divider>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `divider` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% divider /%}

{% divider layout="content" align="center" %}Or continue with{% /divider %}
```

属性の名前と値は React の props と同じです。
