## MDX で使う

`Textarea` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Textarea } from "@pelagornis/page/components";

<Textarea placeholder="Write a comment…" rows={4} aria-label="Comment" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `textarea` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% textarea placeholder="Write a comment…" rows=4 ariaLabel="Comment" /%}
```

属性の名前と値は React の props と同じです。
