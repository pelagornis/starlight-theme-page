## MDX で使う

`Box` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Box } from "@pelagornis/page/components";

<Box padding="sizeLarge" background="backgroundSurface" radius="roundedLarge">
  Surface box
</Box>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `box` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% box padding="sizeLarge" background="backgroundSurface" radius="roundedLarge" %}
Surface box
{% /box %}
```

属性の名前と値は React の props と同じです。
