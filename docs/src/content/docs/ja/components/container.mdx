## MDX で使う

`Container` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Container } from "@pelagornis/page/components";

<Container padding="sizeXXLarge">
  Centered content
</Container>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `container` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% container padding="sizeXXLarge" %}
Centered content
{% /container %}
```

属性の名前と値は React の props と同じです。
