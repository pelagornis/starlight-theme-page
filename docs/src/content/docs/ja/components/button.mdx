## MDX で使う

`Button` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `button` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% button variant="primary" %}Continue{% /button %}
{% button variant="outline" size="sm" %}Cancel{% /button %}
```

属性の名前と値は React の props と同じです。
