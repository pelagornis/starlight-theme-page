## MDX で使う

`Progress` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Progress } from "@pelagornis/page/components";

<Progress value={60} aria-label="Upload" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `progress` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% progress value=60 ariaLabel="Upload" /%}
```

属性の名前と値は React の props と同じです。
