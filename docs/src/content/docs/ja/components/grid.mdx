## MDX で使う

`Grid` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Grid } from "@pelagornis/page/components";

<Grid columns={3} gap="sizeMedium">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</Grid>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `grid` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% grid columns=3 gap="sizeMedium" %}
One

Two

Three
{% /grid %}
```

属性の名前と値は React の props と同じです。
