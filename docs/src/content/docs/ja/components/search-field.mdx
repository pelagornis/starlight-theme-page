## MDX で使う

`Search Field` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。入力に反応するので、`client:load` を付けてハイドレートします。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { SearchField } from "@pelagornis/page/components";

<SearchField client:load defaultValue="tokens" aria-label="Search" />
```

## Markdoc で使う

Markdoc のタグは Astro コンポーネントを描画しますが、このコンポーネントにはクライアントの状態が必要です。例をハイドレートする `.astro` ファイルで包み、そのファイルをタグとして登録してください。

```astro title="src/components/markdoc/SearchFieldExample.astro"
---
import SearchFieldExample from "../SearchFieldExample";
---

<SearchFieldExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "search-field-example": {
      render: component("./src/components/markdoc/SearchFieldExample.astro"),
      selfClosing: true,
    },
  },
});
```

```md title="src/content/docs/example.mdoc"
{% search-field-example /%}
```
