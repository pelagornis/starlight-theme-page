## MDX で使う

`Input` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Input } from "@pelagornis/page/components";

<Input placeholder="you@example.com" aria-label="Email" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `input` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% input placeholder="you@example.com" ariaLabel="Email" /%}
```

属性の名前と値は React の props と同じです。
