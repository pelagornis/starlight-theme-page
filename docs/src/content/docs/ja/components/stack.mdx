## MDX で使う

`Stack` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button, Stack } from "@pelagornis/page/components";

<Stack direction="row" gap="sizeSmall" align="center">
  <Button variant="outline">Cancel</Button>
  <Button variant="primary">Save</Button>
</Stack>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `stack` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% stack direction="row" gap="sizeSmall" align="center" %}
{% button variant="outline" %}Cancel{% /button %}
{% button variant="primary" %}Save{% /button %}
{% /stack %}
```

属性の名前と値は React の props と同じです。
