## MDX で使う

`Chip` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Chip } from "@pelagornis/page/components";

<Chip variant="filled">Astro</Chip>
<Chip variant="outline" size="sm">React</Chip>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `chip` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% chip variant="filled" %}Astro{% /chip %}
```

属性の名前と値は React の props と同じです。
