## MDX で使う

`Spacer` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button, Spacer, Stack } from "@pelagornis/page/components";

<Stack direction="row">
  <span>Project</span>
  <Spacer />
  <Button size="sm">New file</Button>
</Stack>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `stack` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% stack direction="row" %}
Project
{% spacer /%}
{% button size="sm" %}New file{% /button %}
{% /stack %}
```

属性の名前と値は React の props と同じです。
