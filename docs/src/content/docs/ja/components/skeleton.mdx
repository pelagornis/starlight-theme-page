
## MDX で使う

`Skeleton` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Skeleton } from "@pelagornis/page/components";

<Skeleton width="60%" height={16} />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `skeleton` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% skeleton width="60%" height=16 /%}
```

属性の名前と値は React の props と同じです。
