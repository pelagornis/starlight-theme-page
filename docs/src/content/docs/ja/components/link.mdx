## MDX で使う

`Link` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Link } from "@pelagornis/page/components";

<Link href="https://ui.pelagornis.com/" target="_blank">RefineUI</Link>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `link` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% link href="https://ui.pelagornis.com/" target="_blank" %}RefineUI{% /link %}
```

属性の名前と値は React の props と同じです。
