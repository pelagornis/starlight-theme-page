## MDX で使う

`Navigation Menu` は React の状態を共有する複数のパーツで構成されます。MDX に書いた子要素はそれぞれ別のアイランドとして描画されるため、パーツ同士がつながりません。上の例のように `.tsx` ファイルで組み立て、そのファイルをインポートしてください。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import NavigationMenuExample from "../../components/NavigationMenuExample";

<NavigationMenuExample client:load />
```

`client:load` はページの読み込み時にアイランドをハイドレートします。ページの下の方にあるコンテンツには `client:visible` を使ってください。

## Markdoc で使う

Markdoc のタグは Astro コンポーネントを描画しますが、このコンポーネントにはクライアントの状態が必要です。例をハイドレートする `.astro` ファイルで包み、そのファイルをタグとして登録してください。

```astro title="src/components/markdoc/NavigationMenuExample.astro"
---
import NavigationMenuExample from "../NavigationMenuExample";
---

<NavigationMenuExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "navigation-menu-example": {
      render: component("./src/components/markdoc/NavigationMenuExample.astro"),
      selfClosing: true,
    },
  },
});
```

```md title="src/content/docs/example.mdoc"
{% navigation-menu-example /%}
```
