## MDX で使う

`Spinner` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Spinner } from "@pelagornis/page/components";

<Spinner size="lg" label="Loading…" labelPosition="right" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `spinner` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% spinner size="lg" label="Loading…" labelPosition="right" /%}
```

属性の名前と値は React の props と同じです。
