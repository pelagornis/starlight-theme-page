## MDX で使う

`Badge` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Badge } from "@pelagornis/page/components";

<Badge variant="success">Stable</Badge>
<Badge variant="danger" layout="number">12</Badge>
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `badge` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% badge variant="success" %}Stable{% /badge %}
```

属性の名前と値は React の props と同じです。
