## MDX で使う

`Radio` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Radio } from "@pelagornis/page/components";

<Radio name="plan" value="basic" label="Basic" defaultChecked />
<Radio name="plan" value="pro" label="Pro" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `radio` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% radio name="plan" value="basic" label="Basic" defaultChecked=true /%}
{% radio name="plan" value="pro" label="Pro" /%}
```

属性の名前と値は React の props と同じです。
