## MDX で使う

`Checkbox` は `.mdx` ページにそのまま書けます。frontmatter の下でインポートしてください。サーバーで描画されるので、client ディレクティブは要りません。

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Checkbox } from "@pelagornis/page/components";

<Checkbox label="Accept terms" description="Required to continue" />
```

## Markdoc で使う

`pageMarkdoc()` がこのコンポーネントの `checkbox` タグを登録します。`markdoc.config.mjs` にプリセットを一度追加すれば（[Markdoc で使う](/ja/guides/markdoc/)を参照）、どの `.mdoc` ページでもタグを書けます。

```md title="src/content/docs/example.mdoc"
{% checkbox label="Accept terms" description="Required to continue" /%}
```

属性の名前と値は React の props と同じです。
