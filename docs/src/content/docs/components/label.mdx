## Use in MDX

`Label` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Label } from "@pelagornis/page/components";

<Label htmlFor="email" required>Email address</Label>
```

## Use in Markdoc

`pageMarkdoc()` registers a `label` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% label htmlFor="email" required=true %}Email address{% /label %}
```

Attributes use the same names and values as the React props.
