## Use in MDX

`Text` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Text } from "@pelagornis/page/components";

<Text as="p" variant="titleMd">Title medium</Text>
<Text variant="captionMd">Caption</Text>
```

## Use in Markdoc

`pageMarkdoc()` registers a `text` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% text as="p" variant="titleMd" %}Title medium{% /text %}
```

Attributes use the same names and values as the React props.
