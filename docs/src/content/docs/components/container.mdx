## Use in MDX

`Container` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Container } from "@pelagornis/page/components";

<Container padding="sizeXXLarge">
  Centered content
</Container>
```

## Use in Markdoc

`pageMarkdoc()` registers a `container` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% container padding="sizeXXLarge" %}
Centered content
{% /container %}
```

Attributes use the same names and values as the React props.
