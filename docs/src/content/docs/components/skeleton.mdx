## Use in MDX

`Skeleton` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Skeleton } from "@pelagornis/page/components";

<Skeleton width="60%" height={16} />
```

## Use in Markdoc

`pageMarkdoc()` registers a `skeleton` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% skeleton width="60%" height=16 /%}
```

Attributes use the same names and values as the React props.
