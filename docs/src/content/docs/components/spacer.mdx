## Use in MDX

`Spacer` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button, Spacer, Stack } from "@pelagornis/page/components";

<Stack direction="row">
  <span>Project</span>
  <Spacer />
  <Button size="sm">New file</Button>
</Stack>
```

## Use in Markdoc

`pageMarkdoc()` registers a `stack` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% stack direction="row" %}
Project
{% spacer /%}
{% button size="sm" %}New file{% /button %}
{% /stack %}
```

Attributes use the same names and values as the React props.
