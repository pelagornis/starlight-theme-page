## Use in MDX

`Checkbox` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Checkbox } from "@pelagornis/page/components";

<Checkbox label="Accept terms" description="Required to continue" />
```

## Use in Markdoc

`pageMarkdoc()` registers a `checkbox` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% checkbox label="Accept terms" description="Required to continue" /%}
```

Attributes use the same names and values as the React props.
