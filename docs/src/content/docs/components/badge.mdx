## Use in MDX

`Badge` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Badge } from "@pelagornis/page/components";

<Badge variant="success">Stable</Badge>
<Badge variant="danger" layout="number">12</Badge>
```

## Use in Markdoc

`pageMarkdoc()` registers a `badge` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% badge variant="success" %}Stable{% /badge %}
```

Attributes use the same names and values as the React props.
