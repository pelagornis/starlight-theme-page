## Use in MDX

`Spinner` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Spinner } from "@pelagornis/page/components";

<Spinner size="lg" label="Loading…" labelPosition="right" />
```

## Use in Markdoc

`pageMarkdoc()` registers a `spinner` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% spinner size="lg" label="Loading…" labelPosition="right" /%}
```

Attributes use the same names and values as the React props.
