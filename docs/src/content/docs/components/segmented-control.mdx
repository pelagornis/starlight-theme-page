## Use in MDX

`Segmented Control` is composed from parts that share React state. Children written in MDX are rendered as separate islands, so the parts can't reach each other. Put the composition in a `.tsx` file, like the example above, and import that file instead.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import SegmentedControlExample from "../../components/SegmentedControlExample";

<SegmentedControlExample client:load />
```

`client:load` hydrates the island on page load. Use `client:visible` for content far down the page.

## Use in Markdoc

Markdoc tags render Astro components, and this one needs client state. Wrap the example in an `.astro` file that hydrates it, then register that file as a tag.

```astro title="src/components/markdoc/SegmentedControlExample.astro"
---
import SegmentedControlExample from "../SegmentedControlExample";
---

<SegmentedControlExample client:load />
```

```js title="markdoc.config.mjs" ins={7-12}
import { component, defineMarkdocConfig } from "@astrojs/markdoc/config";
import starlightMarkdoc from "@astrojs/starlight-markdoc";
import pageMarkdoc from "@pelagornis/page/markdoc";

export default defineMarkdocConfig({
  extends: [starlightMarkdoc(), pageMarkdoc()],
  tags: {
    "segmented-control-example": {
      render: component("./src/components/markdoc/SegmentedControlExample.astro"),
      selfClosing: true,
    },
  },
});
```
