## Use in MDX

`Grid` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Grid } from "@pelagornis/page/components";

<Grid columns={3} gap="sizeMedium">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
</Grid>
```

## Use in Markdoc

`pageMarkdoc()` registers a `grid` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% grid columns=3 gap="sizeMedium" %}
One

Two

Three
{% /grid %}
```

Attributes use the same names and values as the React props.
