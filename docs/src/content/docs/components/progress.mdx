## Use in MDX

`Progress` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Progress } from "@pelagornis/page/components";

<Progress value={60} aria-label="Upload" />
```

## Use in Markdoc

`pageMarkdoc()` registers a `progress` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% progress value=60 ariaLabel="Upload" /%}
```

Attributes use the same names and values as the React props.
