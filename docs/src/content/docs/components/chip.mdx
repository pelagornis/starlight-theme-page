## Use in MDX

`Chip` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Chip } from "@pelagornis/page/components";

<Chip variant="filled">Astro</Chip>
<Chip variant="outline" size="sm">React</Chip>
```

## Use in Markdoc

`pageMarkdoc()` registers a `chip` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% chip variant="filled" %}Astro{% /chip %}
```

Attributes use the same names and values as the React props.
