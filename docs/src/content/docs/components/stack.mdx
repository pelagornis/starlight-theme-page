## Use in MDX

`Stack` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button, Stack } from "@pelagornis/page/components";

<Stack direction="row" gap="sizeSmall" align="center">
  <Button variant="outline">Cancel</Button>
  <Button variant="primary">Save</Button>
</Stack>
```

## Use in Markdoc

`pageMarkdoc()` registers a `stack` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% stack direction="row" gap="sizeSmall" align="center" %}
{% button variant="outline" %}Cancel{% /button %}
{% button variant="primary" %}Save{% /button %}
{% /stack %}
```

Attributes use the same names and values as the React props.
