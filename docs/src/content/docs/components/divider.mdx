## Use in MDX

`Divider` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Divider } from "@pelagornis/page/components";

<Divider />

<Divider layout="content" align="center">Or continue with</Divider>
```

## Use in Markdoc

`pageMarkdoc()` registers a `divider` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% divider /%}

{% divider layout="content" align="center" %}Or continue with{% /divider %}
```

Attributes use the same names and values as the React props.
