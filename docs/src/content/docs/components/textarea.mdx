## Use in MDX

`Textarea` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Textarea } from "@pelagornis/page/components";

<Textarea placeholder="Write a comment…" rows={4} aria-label="Comment" />
```

## Use in Markdoc

`pageMarkdoc()` registers a `textarea` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% textarea placeholder="Write a comment…" rows=4 ariaLabel="Comment" /%}
```

Attributes use the same names and values as the React props.
