## Use in MDX

`Link` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Link } from "@pelagornis/page/components";

<Link href="https://ui.pelagornis.com/" target="_blank">RefineUI</Link>
```

## Use in Markdoc

`pageMarkdoc()` registers a `link` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% link href="https://ui.pelagornis.com/" target="_blank" %}RefineUI{% /link %}
```

Attributes use the same names and values as the React props.
