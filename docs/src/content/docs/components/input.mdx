## Use in MDX

`Input` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Input } from "@pelagornis/page/components";

<Input placeholder="you@example.com" aria-label="Email" />
```

## Use in Markdoc

`pageMarkdoc()` registers a `input` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% input placeholder="you@example.com" ariaLabel="Email" /%}
```

Attributes use the same names and values as the React props.
