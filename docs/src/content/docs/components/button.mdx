## Use in MDX

`Button` can be written straight in an `.mdx` page. Import it below the frontmatter. It renders on the server, so no client directive is needed.

```mdx title="src/content/docs/example.mdx"
---
title: Example
---

import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

## Use in Markdoc

`pageMarkdoc()` registers a `button` tag for this component. Add the preset once in `markdoc.config.mjs` (see [Use in Markdoc](/guides/markdoc/)), then write the tag in any `.mdoc` page.

```md title="src/content/docs/example.mdoc"
{% button variant="primary" %}Continue{% /button %}
{% button variant="outline" size="sm" %}Cancel{% /button %}
```

Attributes use the same names and values as the React props.
