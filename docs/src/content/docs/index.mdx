## Docs shell

Page replaces Starlight’s chrome with RefineUI overrides.

- Header with the links you configure, command search, and a theme button
- Resizable sidebar on desktop, and a drawer on small screens
- Footer with navigation, social links, copyright, and the language select
- Light and dark themes from RefineUI semantic tokens

## Components in your pages

Every RefineUI component is exported from `@pelagornis/page/components`.

```mdx
import { Button } from "@pelagornis/page/components";

<Button variant="primary">Continue</Button>
```

- [Use in MDX](/guides/mdx/) covers imports, client directives, and compound components.
- [Use in Markdoc](/guides/markdoc/) covers the `pageMarkdoc()` preset and its tags.
- [Components](/components/) lists all 59 components with live previews, example source, and props.
